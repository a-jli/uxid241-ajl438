## ABOUT
This repository contains the cumulative final for IDM 232, an online cookbook web app backed by a database with an admin area for adding, editing, and deleting recipes. Users will be able to search for recipes and filter by category.

### Beta Milestone
Users are currently able to view recipes, search for recipes by title and description, and log into the admin area to add/edit/delete recipes.

## Running Locally
1. Create database
2. Load schema.sql
3. Copy config.example.php to config.php and fill in credentials.
4. Place the project inside your 'htdocs' folder and open it through localhost with XAMPP/MAMP running

## Admin Login
After creating an account through the register page, users will be able to access the gated admin area.

## Feature Built for Beta
Search

To search through recipes, type into the search bar and press the "Search" button.
