## ABOUT
This repository contains the cumulative final for IDM 232, an online cookbook web app backed by a database with an admin area for adding, editing, and deleting recipes. Users will be able to search for recipes and filter by category.


## Running Locally
1. Create database
2. Load schema.sql
3. Copy config.example.php to config.php and fill in credentials.
4. Place the project inside your 'htdocs' folder and open it through localhost with XAMPP or MAMP running
